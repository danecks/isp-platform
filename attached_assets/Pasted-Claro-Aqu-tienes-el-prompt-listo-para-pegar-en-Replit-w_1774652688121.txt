5. Validación al crear anticipo (manual y WhatsApp)

Aplicar esta lógica tanto en:
	•	flujo manual desde admin
	•	flujo por WhatsApp

Caso A — Dentro del límite

Si el monto solicitado es menor o igual al restante:
	•	aceptar normalmente

Caso B — Excede el límite

Si el monto solicitado excede el restante:
	•	no rechazar de forma seca
	•	responder con una lógica humana y guiada

Ejemplo:
Límite Q500, ya pidió Q100, restante Q400.
Si solicita Q500, el sistema debe responder:

“Tu monto disponible para este período es de Q400.
Puedes:
	1.	Solicitar el monto disponible (Q400)
	2.	Ingresar un monto menor
	3.	Cancelar la solicitud”

Y esperar la siguiente respuesta del usuario.
