Recuerda que el Pizarrón Operativo está conectado a Pre Planilla, así que la integración de SSA no debe pensarse solo como cobertura operativa visual, sino como parte de un flujo que sigue vivo hasta que el servicio quede listo para pre planilla y cierre administrativo.

Corrección importante al diseño actual

Hoy la tarjeta SSA desaparece del Pizarrón cuando se asigna un agente, porque el panel solo contempla solicitudes pendientes de cobertura.

Eso ya no es suficiente.

Quiero que rediseñes la lógica del Pizarrón para que las tarjetas SSA sigan un flujo compatible con:
	•	Operaciones
	•	Pool de agentes
	•	Pre Planilla
	•	Facturación
	•	Cierre administrativo

Regla principal

Una solicitud SSA no debe desaparecer del Pizarrón solo porque ya fue asignada.

Debe seguir visible mientras todavía tenga relevancia para:
	•	control operativo
	•	validación de ejecución
	•	pre planilla
	•	facturación
	•	cierre

Propuesta funcional esperada

Quiero que en el Pizarrón las tarjetas SSA tengan al menos estas etapas visibles:

1. Pendiente de cobertura

Condición sugerida:
	•	tarjeta_activa = TRUE
	•	agente_id IS NULL
	•	no cancelada
	•	no cerrada

2. Cubierta / asignada

Condición sugerida:
	•	agente_id IS NOT NULL
	•	estado_operaciones = 'cubierta'
	•	todavía no enviada o consolidada en pre planilla
	•	no cerrada

3. Lista para Pre Planilla o ya vinculada a Pre Planilla

Condición sugerida:
	•	servicio ya cubierto
	•	con datos suficientes para control laboral
	•	con marca o estado de integración a pre planilla

4. Pendiente de facturación / cierre

Condición sugerida:
	•	operación completada
	•	pre planilla completada o validada
	•	falta facturación o cierre administrativo
