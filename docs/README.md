# Documentación ISP, S.A. — Plataforma Operativa

Esta carpeta contiene la documentación oficial del sistema ISP. Está organizada en cuatro documentos complementarios:

| # | Documento | Para quién | Qué contiene |

| 2 | [Documentación Técnica](./02-documentacion-tecnica.md) | Desarrolladores | Arquitectura, endpoints, tablas de BD por módulo |

| 4 | [Diccionario de Datos](./04-diccionario-datos.md) | Todos | Glosario de estados, tipos, conceptos del sistema |

## Mapa del sistema

- **Sitio público**: `ispsa.net` — institucional, contacto, solicitud de empleo, kiosco.
- **Panel administrativo**: `ispsa.net/admin` — operación interna (50+ módulos).
- **Portal de cliente**: `ispsa.net/portal` — vista limitada para clientes.
- **Apps móviles** (vía web): fichaje QR, rondas QR, kiosco, supervisor.

## Convenciones

- **Zona horaria**: Guatemala (GTM-6). Todas las fechas operativas se calculan en hora local.
- **Formato fecha**: `YYYY-MM-DD`.
- **Moneda**: Quetzales (Q.).
- **Identificación**: DPI (13 dígitos) y NIT.

## Cómo mantener esta documentación

Cuando agregues, modifiques o elimines un módulo, actualizá los cuatro archivos en la sección correspondiente. Si introducís un nuevo concepto o estado, agregalo al **Diccionario de Datos**.
